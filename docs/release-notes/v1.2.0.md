# Dev Agent Kit v1.2.0

v1.2.0 adds an integrations registry, Cursor as a third host, and deeper stack guides for FastAPI, NestJS, Vue, Nuxt and Next.js.

## New

- **Integrations registry** — Figma (default), Headroom, claude-mem, Cartographer and Graphify. `install` takes `--with <id>` and `--no-<id>`; the selection is sticky and recorded in `.dev-agent/integrations.json`. Headroom writes its MCP entry (the format was checked against a real 0.40.0 install); claude-mem, Cartographer and Graphify are verify-only. `verify` has a new `warn` state for integrations that are installed but not ready.
- **Cursor as a third host** — `install cursor` and `verify cursor`. Skills and the `AGENTS.md` block are shared with Codex (`.agents/skills/`), and the MCP config goes to `.cursor/mcp.json`. A symlink at `.cursor`, `.codex`, `.agents` or `.dev-agent` is refused before anything is written.
- **Deeper stack guides** — one richer reference per stack (about 130–165 lines each), written from the official documentation, each with a `Targets:` line naming the versions it covers:
  - `backend-architecture`: `fastapi`, `nestjs`.
  - new skill `frontend-architecture` (the 27th): `vue-stack`, `nuxt-stack` (Nuxt 4, with Nuxt 3 differences), `next-stack` (Next.js 14/15/16 differences, including `proxy.ts` and the two-argument `revalidateTag`).
- **`inspect` lists frontend references** next to the backend ones, chosen from the detected frameworks (Nuxt before Vue; none for React alone).

## Compatibility

- `install` and `verify` without a host now include Cursor **when it is detected** (`~/.cursor` or `cursor` on `PATH`). `--all` is unchanged: Claude and Codex only.
- Because of that, a plain `verify` can turn red on a machine with Cursor until `install cursor` has run.
- Skill count goes from 26 to 27; the existing skill names, MCP tool names and config files keep working.

## Limits

- The guides are checked by tests for structure only. Their technical content was reviewed against the official docs by reviewers, but the project owner's own read-through is still pending.
- The manual checklists for real Cursor (loading `.cursor/mcp.json`, reading `.agents/skills/` and `AGENTS.md`, host detection), real Cartographer and claude-mem, and Headroom inside an interactive Claude Code session (the entry stays in "Pending approval") have **not** been run. Headroom with `headroom proxy` and `ANTHROPIC_BASE_URL` was not tested.
- No React-only guide, and no CLI check for a React + FastAPI project showing both reference lists (the selector has its own test).
- Known small items: the stack-guide contract test checks order, size and `Targets:` in one test, and its line count is off by one for a guide of exactly 200 lines.
- The real Claude and Codex benchmarks have **not been run** for this release; nothing here claims a benchmark result.
